平台通过一个 API Key 提供对话、图片和视频模型。先从 API 工作台创建密钥，再获取可用模型并发起请求。

接口页面现在支持在线调试：填写 API Key 和请求参数，即可发送真实请求并查看响应。先阅读[在线调试 API](/api-reference/overview)，或直接用[账户接口](/account)验证密钥。

## 接入流程

1. 在 API 工作台创建 API Key。
2. 确认平台提供的 Base URL，并阅读[鉴权说明](/authentication)。
3. 查询[模型目录](/models)，确认支持的任务和参数。
4. 发起对话请求，或创建图片、视频生成任务。
5. 异步任务按[状态说明](/tasks/status)轮询并保存最终结果。

## 接口约定

对话接口按对应厂商协议返回数据；图片、视频任务与模型目录的返回结构请参照各自页面的完整示例。

首次接入可以按[快速开始](/quickstart)验证密钥和地址，再从[接口总览](/api-overview)选择业务入口。需要完整代码时，使用[SDK 示例](/conversation/sdk-examples)或[Python 任务流程](/tasks/python-example)；出现故障时按[错误处理](/errors)核对原因。
