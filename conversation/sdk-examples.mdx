以下示例使用平台公开模型名，统一从环境变量读取完整服务根地址 `API_BASE_URL` 和密钥 `PLATFORM_API_KEY`。根地址不含版本段；SDK 所需的版本路径按下表添加。真实供应商联调仍需使用实际模型验证。

## Base URL 配置差异

| SDK | 示例配置 | 原因 |
| --- | --- | --- |
| OpenAI Python / JavaScript | `API_BASE_URL` + `/v1` | SDK追加 `/chat/completions`、`/responses` |
| Anthropic Python | `API_BASE_URL` | SDK追加 `/v1/messages` |
| Google GenAI Python | `API_BASE_URL` + `api_version="v1beta"` | SDK构建 `/v1beta/models/...` |

用客户实际地址设置环境变量，保留 Nginx 对外前缀。若工作台地址以 `/v1` 结尾，设置 `API_BASE_URL` 时先移除这个版本段，避免重复追加。模型名从[标准列表](/conversation/models-and-errors)读取，先确认目标协议支持。

OpenAI Python（`pip install openai`）：

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["PLATFORM_API_KEY"],
    base_url=os.environ["API_BASE_URL"].rstrip("/") + "/v1",
)
with client.chat.completions.create(
    model="YOUR_MODEL",
    messages=[{"role": "user", "content": "你好"}],
    max_tokens=512,
    stream=True,
    stream_options={"include_usage": True},
) as stream:
    for chunk in stream:
        if chunk.choices:
            print(chunk.choices[0].delta.content or "", end="", flush=True)
        if chunk.usage:
            print("\n用量:", chunk.usage)
```

OpenAI JavaScript Responses（`npm install openai`）：

```javascript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.PLATFORM_API_KEY,
  baseURL: `${process.env.API_BASE_URL.replace(/\/+$/, "")}/v1`,
});
const stream = await client.responses.create({
  model: "YOUR_MODEL",
  input: "你好",
  max_output_tokens: 512,
  stream: true,
});
for await (const event of stream) {
  if (event.type === "response.output_text.delta") process.stdout.write(event.delta);
  if (event.type === "response.completed") console.log(event.response.usage);
}
```

Anthropic Python（`pip install anthropic`）：

```python
import os
from anthropic import Anthropic

client = Anthropic(
    api_key=os.environ["PLATFORM_API_KEY"],
    base_url=os.environ["API_BASE_URL"].rstrip("/"),
)
with client.messages.stream(
    model="YOUR_MODEL",
    max_tokens=1024,
    messages=[{"role": "user", "content": "你好"}],
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)
    print("\n用量:", stream.get_final_message().usage)
```

Google GenAI Python（`pip install google-genai`）：

```python
import os
from google import genai
from google.genai import types

client = genai.Client(
    api_key=os.environ["PLATFORM_API_KEY"],
    http_options=types.HttpOptions(
        base_url=os.environ["API_BASE_URL"].rstrip("/"),
        api_version="v1beta",
    ),
)
for chunk in client.models.generate_content_stream(model="YOUR_MODEL", contents="你好"):
    print(chunk.text or "", end="", flush=True)
    if chunk.usage_metadata:
        print("\n用量:", chunk.usage_metadata)
```

## 超时与重试

SDK可能自动重试部分网络及 HTTP 错误。生成请求存在已被接受但客户端超时的情况，业务需避免重复操作时，可给 OpenAI / Anthropic Python 客户端设置 `max_retries=0`，OpenAI JavaScript 设置 `maxRetries: 0`，再由业务层核对响应或任务记录后处理。

首次接入先使用较低输出上限验证普通请求，再启用流式。捕获 SDK错误时保存 HTTP 状态、错误正文和请求时间；收集流式最终事件及 usage，连接中途退出时检查平台记录。详见[错误处理](/errors)。
