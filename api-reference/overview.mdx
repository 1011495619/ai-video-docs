文档中的接口页面提供 **Try it** 调试区、请求参数表、响应结构和 cURL、Python、JavaScript 示例。

## 开始调用

<Steps>
  <Step title="准备 API Key">
    在你所属站点的 API 工作台创建密钥。不同客户可以共用这份文档，各自使用所属站点的 API 地址和密钥。
  </Step>
  <Step title="填写客户 API 根地址">
    打开接口的 **Try it** 调试区，在 **Server** 中修改 `baseUrl`，填写 API Key 所属客户的完整 API 根地址，包含协议、域名、可选端口和对外路径前缀。预填值只是默认配置，使用前先核对所属站点。

    例如 `https://api.customer.com/gateway` 或 `https://api.customer.com`。末尾不加 `/`，也不包含 `/v1`、`/v1beta` 或具体接口路径；调试区自动拼接当前接口路径。浏览器会记住所填地址，并在其他接口中继续使用；切换客户时核对地址和 API Key。
  </Step>
  <Step title="验证账户与模型">
    打开[账户接口](/account)，点击 **Try it**，在认证框中填写完整 API Key，再点击 **Send**。Bearer 认证框只填写密钥，前缀由调试区添加。

    查询[图片与视频模型目录](/models)或[对话模型列表](/conversation/models-and-errors)，复制当前账户可用的模型 ID。
  </Step>
  <Step title="填写参数并发送">
    在目标接口填写模型、提示词和所需参数。请求区会生成对应代码；发送后在响应区查看真实 HTTP 状态和返回内容。

    示例里的 `YOUR_IMAGE_MODEL`、`YOUR_CHAT_MODEL` 等是待替换的模型占位值，应填写目录中的实际 ID。
  </Step>
  <Step title="读取生成结果">
    对话请求按协议读取文本；图片和视频异步接口先返回 ID，再到对应查询接口获取最终结果。HTTP 200 的任务查询仍应检查 `status`。
  </Step>
</Steps>

<Note>
  点击 **Send** 会向实际 API 发起请求。生成请求按账户及模型的规则消耗额度；示例响应只是结构说明。调试请求通过 Mintlify 的 API 代理发送。
</Note>

## SaaS 多客户部署

客户可以共用文档站，并按自己的部署方式设置 `baseUrl`：

| 对外部署方式 | `baseUrl` | 账户请求地址 |
| --- | --- | --- |
| 默认 `/api` 前缀 | `https://api.customer-a.com/api` | `https://api.customer-a.com/api/v1/account` |
| Nginx 使用 `/gateway` 前缀 | `https://api.customer-b.com/gateway` | `https://api.customer-b.com/gateway/v1/account` |
| 根路径转发 | `https://api.customer-c.com` | `https://api.customer-c.com/v1/account` |
| 自定义端口和多层前缀 | `https://api.customer-d.com:8443/services/ai` | `https://api.customer-d.com:8443/services/ai/v1/account` |

填写 Nginx 对外暴露的地址，代理负责将请求转发到后端对应接口；新增客户或调整代理前缀无需修改或重新发布文档。线上调试需使用 Mintlify 代理可访问的公网服务地址。

文档站的域名和 API 服务地址分别配置。共享文档站不会自动识别客户所属站点，第一次调试时按 API 工作台提供的地址填写 `baseUrl`。

正文的 cURL、Python 和 JavaScript 示例统一从终端环境变量 `API_BASE_URL` 读取同一个完整根地址，再追加接口路径。浏览器里的 `baseUrl` 与终端环境变量分别保存；设置方式见[快速开始](/quickstart)。

## 同步、异步与流式

- 对话接口将 `stream` 设为 `true` 时使用 SSE。Gemini 流式入口单独使用[流式生成](/api-reference/gemini-stream)，Query 的 `alt` 为 `sse`。
- OpenAI 图片同步接口会等待生成结果，长时间任务可能触及调试代理的等待限制。优先使用[异步图片生成](/api-reference/image-generations-async)或[异步图片编辑](/api-reference/image-edits-async)，再[查询批次](/api-reference/get-image-batch)。
- 单个图片任务、图片批次、视频任务、文件及 Responses 各有自己的 ID 和查询路径。使用创建或上传接口实际返回的 ID。

多轮上下文、SDK 接入、任务轮询和错误处理仍可在 **接入指南** 中查阅。
